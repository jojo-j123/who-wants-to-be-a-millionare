# Who Wants to Be a Millionaire — offline show system

A complete, broadcast-styled quiz show you can run in a hall with **no internet at all**:
a big **stage display** for the audience and a **host remote** you drive from your phone.

Questions, prize ladder, lifelines, timer and branding are all editable from the phone,
and everything is stored in plain JSON files next to the code.

---

## Quick start

You need **Node.js 16 or newer** and nothing else. There are **no dependencies to install** —
the server is built entirely on the Node standard library, so `npm install` is not required.

```bash
node server.js
```

or double-click **`start.sh`** (macOS / Linux) or **`start.bat`** (Windows).

Then:

| Screen | Address | Where to open it |
|---|---|---|
| Launcher | `http://localhost:8080/` | The show laptop |
| **Stage display** | `http://localhost:8080/display` | The TV / projector — press **F** for fullscreen |
| **Host remote** | `http://localhost:8080/admin` | Your phone |

Use a different port with `node server.js --port 3000`.

## Running the show with no internet

This is the point of the project, so it is worth being precise about it.

**Nothing is fetched from the network at any point.** There are no CDN scripts, no web fonts,
no Google/analytics calls, no sound files to download and no external QR service. The
graphics are drawn with CSS, the sound effects are **synthesised live in the browser** with
the Web Audio API, and the QR code is generated by a QR encoder included in this repo.

To get your phone talking to the laptop without an internet connection, use any one of these:

1. **A router with no internet.** Any Wi-Fi router or travel router works. The laptop and the
   phone just need to be on the same network — the router does not need a working uplink.
2. **A phone hotspot with mobile data turned off.** Start the hotspot on your phone, join it
   from the laptop, then browse to the laptop's address from the phone. Cellular data can stay
   off; the hotspot is only acting as a local network.
3. **An ethernet cable** between the laptop and the display machine, if you are driving the
   display from a second computer.

When the server starts it prints the addresses your phone should use:

```
On the same Wi-Fi / hotspot (no internet needed):
  http://192.168.1.24:8080/admin   (wlan0)
```

The **Screens** tab in the remote shows the same addresses plus a **QR code** — point your
phone camera at the laptop screen and you are in.

### If the Wi-Fi drops mid-show

* The stage display and the remote both **reconnect on their own** and re-sync to the
  server's state — you never lose the current question, level or lifelines.
* Both pages are installed as an offline PWA, so a phone that has loaded the remote once will
  still open it if the network stutters.
* The game state lives on the **server**, not in the browser, so refreshing any screen (or
  swapping to a different phone entirely) picks up exactly where the show was.

## Running the show

Open **Control** on your phone:

1. Type the contestant's name, press **Start show**.
2. Press **Next question →** to put the first question on the stage screen.
3. The contestant answers out loud. Tap that answer on your phone — a **✓** marks the correct
   one, and only you can see it.
4. Press **Lock it in** for the dramatic pause, then **Reveal answer**.
5. Press **Next question →** to climb the ladder.

Other controls:

* **Shuffle** — swap in a different question at the same level.
* **Walk away** — the contestant takes the money earned so far.
* **Jump to level** — start anywhere on the ladder (handy for rehearsals and short rounds).
* **Timer** — start / pause / reset, change the seconds per question, or switch it off entirely.
* **Put on stage** — on the Questions tab, send any specific question to the display.

### Lifelines

Tap a lifeline in the remote and it plays out on the stage screen:

| Lifeline | What happens |
|---|---|
| **50:50** | Removes two wrong answers. It never removes the right one. |
| **Phone a Friend** | Asks you for the friend's name and what they say. Leave the text blank and a plausible hint is generated for you (more often right on easy questions than hard ones). A countdown runs on stage. |
| **Ask the Audience** | Shows an animated bar chart. The crowd leans towards the correct answer, less confidently as the questions get harder, and any answer removed by 50:50 gets 0%. |
| **Switch Question** | Replaces the current question with a fresh one at the same difficulty. |

**Reset all** frees every lifeline — useful between contestants. You can also disable
individual lifelines, or add your own (see below).

## Customising the show

Everything below is edited from the phone; changes appear on the stage display immediately.

### Questions — the *Questions* tab

* Search and filter by category or difficulty.
* **+ New** writes a question: text, four answers, which one is right, category, and a
  difficulty band (Easy = levels 1–5, Medium = 6–10, Hard = 11–15).
* **Export JSON** downloads the whole show — questions *and* settings — as a backup.
* **Import JSON** loads a file, either **replacing** the bank or **adding** to it. The previous
  bank is always kept in `data/backups/` first.

You can also edit `data/questions.json` directly in a text editor:

```json
{
  "version": 1,
  "questions": [
    {
      "id": "q001",
      "text": "Which planet is known as the Red Planet?",
      "answers": ["Venus", "Mars", "Jupiter", "Mercury"],
      "correct": 1,
      "difficulty": 1,
      "category": "Science"
    }
  ]
}
```

`correct` is a **0-based index** into `answers` — `0` = A, `1` = B, `2` = C, `3` = D.
`difficulty` is `1`, `2` or `3`. The bank ships with 45 questions to get you started.

### Prize ladder, lifelines and branding — the *Setup* tab

* **Branding** — change the two title lines and the currency symbol. Run it as "WHO WANTS TO BE
  A ENGINEER?", in £ or € or anything else.
* **Prize ladder** — edit any amount, add or remove levels, and tap **◆** to mark a level as a
  guaranteed safe haven. Two presets are built in: the classic 15-level ladder and a quicker
  10-level one. Levels renumber themselves.
* **Lifelines** — rename them, switch any of them off, or **+ Custom** to add your own house
  rule ("Ask the host", "Swap with a teammate"). A custom lifeline announces itself on the
  stage screen with whatever text you type.
* **Stage display** — hide the ladder, timer, lifeline buttons or question counter, and set the
  sound volume.
* **Phone a friend** — the default friend name and how long the call lasts.

Press **Save settings** to write them to `data/settings.json`.

### Locking the remote

Anyone on the same Wi-Fi could otherwise open `/admin` and take over your show. Set a
**Remote PIN** in Setup and every control and edit needs it; the stage display keeps working
without one. Leave it blank for no PIN. The PIN is never sent to the display screen.

## How it fits together

```
      data/questions.json ─┐
      data/settings.json  ─┤
                           ▼
   phone  ──POST /api/action──►  server.js  ──SSE /api/stream──►  stage display
  /admin  ◄──── snapshot ─────  (game state)  ──── snapshot ────►  (and back to the phone)
```

The server holds the one authoritative copy of the game state. The remote sends **actions**
(`answer/lock`, `lifeline/use`, …), the server applies them and pushes a fresh snapshot to
every connected screen over Server-Sent Events. That is why any screen can reconnect at any
time and immediately be correct.

| Path | What it is |
|---|---|
| `server.js` | HTTP server, REST API, live event stream |
| `lib/game.js` | The rules — every state change happens here |
| `lib/api.js` | Validation for questions and settings |
| `lib/store.js` | Atomic JSON file reads/writes and backups |
| `lib/defaults.js` | Factory settings, used if `data/settings.json` is missing |
| `public/display.html` + `css/display.css` + `js/display.js` | The stage screen |
| `public/admin.html` + `css/admin.css` + `js/admin.js` | The phone remote |
| `public/js/audio.js` | Synthesised music and stings — no audio files |
| `public/js/qr.js` | Self-contained QR encoder for the connect-your-phone code |
| `public/js/bus.js` | Reconnecting state sync shared by both screens |
| `public/sw.js` | Service worker that caches the app for offline use |
| `data/` | Your questions and settings — the only files you need to back up |

### HTTP API

Read-only endpoints need no PIN; everything else takes the PIN in an `X-Admin-Pin` header.

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/api/state` | Current snapshot |
| `GET` | `/api/stream` | Live updates (SSE) |
| `GET` | `/api/info` | Port, LAN addresses, whether a PIN is set |
| `POST` | `/api/action` | Drive the show — one action or an array of them |
| `GET`/`PUT` | `/api/settings` | Read / replace settings |
| `GET`/`POST`/`PUT` | `/api/questions` | List / add / replace the bank |
| `PUT`/`DELETE` | `/api/questions/:id` | Edit / remove one question |
| `GET` | `/api/export` | Whole show as one JSON file |
| `POST` | `/api/import` | Load a show file (`mode: "append"` or `"replace"`) |

## Tests

```bash
node test/run-tests.js
```

Boots the real server on a spare port and drives a full show through the HTTP API: climbing
all 15 levels, wrong answers falling back to the safe haven, walking away, every lifeline,
the server-side timer, question editing and validation, settings and ladder changes,
export/import, the live event stream, and PIN protection. It works on a throwaway copy of
`data/` and restores it afterwards.

## Troubleshooting

**The phone cannot open the address.** Check both devices are on the same network, and that the
laptop's firewall allows incoming connections on port 8080 (Windows asks the first time — say
yes to *Private networks*). Some public/guest Wi-Fi has "client isolation" switched on, which
blocks devices from seeing each other — use a hotspot instead.

**No sound on the stage display.** Browsers block audio until the page is interacted with.
Click anywhere on the display once, and check the speaker button in the top right.

**The display looks cramped.** Press **F** for fullscreen. The whole layout scales with the
window, so it fits anything from a laptop to a 4K projector; below about 900px wide it drops
the ladder and stacks the answers.

**I want to start completely fresh.** Delete `data/settings.json` and restart — factory
settings are rewritten. Delete `data/questions.json` for an empty bank.
